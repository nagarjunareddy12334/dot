# ✨ Constellation Portrait Cinema

A romantic cinematic web application where a pure black screen transforms into a glowing white-dot constellation portrait of your loved one.

## 🌟 Features
- **Pulsating Celestial Heart Reveal**: Over 14,000 stardust particles gather to form a beating glowing heart, pulsing to an acoustic heartbeat.
- **Blooming Transformation**: The heart gently blossoms outward and assembles into the portrait with pinpoint white-dot stippling.
- **Diamond Sparkles (`✦`)**: Real-time cross-star flares on jewelry, eyes, and smile.
- **Floating Rose Petals & Starlight**: Ambient petals and twinkling stars drifting in the background.
- **Built-in Romantic Audio**: Ambient piano and celesta soundtrack synthesized live using Web Audio API (no external MP3 files needed).
- **Interactive Ripple**: Touch or mouse movement creates water-wave disturbances in the stars that smoothly spring back into place.
- **Video Recording**: One-click **Record & Export Video** feature that captures the 60 FPS animation directly to a downloadable video file.
- **Photo Upload & Drag-and-Drop**: Upload any photo to immediately generate a custom constellation animation.

## 🚀 How to Run Locally
Simply double-click `Start Cinema.bat` or open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Brave).
